Realizados\n\n### 1. **views.py** - Completado CRUD\n\n#### Cambio 1: Creación de clase de permisos\n```python\nclass PublicReadOnly(BasePermission):\n    \"\"\"\n    Permiso que permite lectura pública (GET) pero requiere autenticación para escritura.\n    \"\"\"\n    def has_permission(self, request, view):\n        if request.method in SAFE_METHODS:\n            return True  # GET, HEAD, OPTIONS público\n        return request.user and request.user.is_authenticated  # POST/PUT/DELETE requiere auth\n```\n\n#### Cambio 2: EstandarViewSet\n- `ReadOnlyModelViewSet` → `ModelViewSet` (habilita POST/PUT/DELETE)\n- `permission_classes = [AllowAny]` → `permission_classes = [PublicReadOnly]`\n- Método `get_queryset()` para filtrar por estado en list\n- Preserva todos los endpoints de lectura existentes\n\n#### Cambio 3: CriterioViewSet\n- `ReadOnlyModelViewSet` → `ModelViewSet`\n- `permission_classes = [AllowAny]` → `permission_classes = [PublicReadOnly]`\n- Agregado filtro `estado` en `filterset_fields`\n- Método `get_queryset()` para filtrar por estado en list\n- Preserva endpoints de lectura avanzada\n\n#### Cambio 4: DocumentoNormativoViewSet\n- `ReadOnlyModelViewSet` → `ModelViewSet`\n- `permission_classes = [AllowAny]` → `permission_classes = [PublicReadOnly]`\n- Método `get_serializer_class()` para usar diferentes serializers\n  - Lectura: `DocumentoNormativoSerializer` (con criterios anidados)\n  - Escritura: `DocumentoNormativoWriteSerializer` (con gestión de criterios)\n\n### 2. **serializers.py** - Soporte para escritura\n\n#### required=False\n    )\n    \n    # Métodos create() y update() para manejar relaciones M2M\n```\n\n**Ventajas:**\n- Permite enviar array de IDs: `criterios_relacionados_ids: [1, 2, 3]`\n-
